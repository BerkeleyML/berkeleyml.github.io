{%- comment -%} Dark mode. Just the Docs builds just-the-docs-dark.css from _sass/color_schemes/dark.scss. It is loaded after the default (light) stylesheet and is active when the system prefers dark, unless the visitor picked a theme with the header toggle (saved in localStorage as "theme"). The script runs before the body renders, so there is no flash of the wrong theme. siteTheme.set('light' | 'dark') switches the theme and fires a "site-theme-change" event, which widgets that style themselves in JavaScript (the calendar) listen for. {%- endcomment -%}
